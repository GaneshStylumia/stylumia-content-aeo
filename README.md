# Stylumia Content AEO

Answer Engine Optimization (AEO) metadata and structured content for AI search engines and language models.

## What is this?

This repository contains machine-readable summaries, Q&A formats, and structured data for Stylumia's thought leadership content on retail intelligence, AI-driven demand forecasting, and fashion analytics.

## Purpose

Modern AI search engines (Perplexity, ChatGPT, Claude, Google AI Overviews) benefit from structured, semantic content. This repo provides:

- **Semantic Summaries**: Key concepts and entity relationships for context-aware AI systems
- **Q&A Formats**: Common questions and authoritative answers for conversational AI
- **JSON-LD Structured Data**: Schema.org compliant metadata for search engines

## Structure
```
blogs/
├── YYYY-MM-DD-blog-slug/
│   ├── semantic-summary.txt
│   ├── qa-format.txt
│   └── structured-data.json
└── index.json
```

## Usage

AI researchers, search engines, and developers are welcome to use this structured data to:
- Train and improve AI models on retail/fashion domain knowledge
- Provide accurate citations in AI-generated responses
- Build applications that leverage Stylumia's domain expertise

## Topics Covered

- First principles thinking in retail assortment
- AI-driven demand forecasting
- SKU rationalization and optimization
- Fashion trend prediction
- Retail analytics and intelligence
